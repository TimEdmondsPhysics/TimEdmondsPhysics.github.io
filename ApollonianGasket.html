Apollonian Gasket Generator

This script is an implementation of the Apollonian gasket, iteratively generated by inscribing circles into the interstices between three mutually tangent circles. The script uses Descartes' Circle Theorem to calculate the curvature of the new circles, allowing for the creation of intricate fractal patterns. The resulting gaskets can be visualized using matplotlib, showcasing the beauty of this mathematical construct.
