Counting Capacitor Circuits - Project Euler #155

This is my solution to the counting capacitors problem from Project Euler. The problem asks for the number of distinct capacitance values that can be made by combining up to n identical capacitors in series and parallel. I implemented a recursive algorithm that generates all possible combinations of capacitors and calculates their equivalent capacitance.
